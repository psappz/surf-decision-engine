# Spot catalog

Initial active recommendation spots: Odeceixe, Amoreira, Monte Clérigo, Monte Clérigo South, Arrifana, Arrifana Reef, Vale Figueiras, Bordeira North, Bordeira Central, Amado, Amado South.

Observation/advanced-only tier: Vale dos Homens, Carriagem, Canal. These remain visible but are not active recommendation candidates in the first prototype and carry lower base confidence.

Structured values live in `app/seed_data.py`: code, slug, name, beach/zone, coordinates, type, difficulty, swell/wind/tide preferences, exposure/shelter, hazards, access notes, and base confidence. Values are provisional and centralized for field review.
